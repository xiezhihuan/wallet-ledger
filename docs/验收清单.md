## 本次新增验收

### 已自动验证

- 旧数据库先生成迁移前备份，再升级到包含 `version`、`bill_changes`、`bill_reviews`、`mcp_authorizations`、`mcp_audit` 的结构，原账单和附件可读。
- MCP 客户端取账单描述和图片，预览错误金额/日期/分类，带授权码写入，查询完整修改记录，统计与明细一致，再恢复到修改前。
- 无授权码、过期、撤销、单笔越权、版本冲突、非法金额/日期/分类、重复 request_id、并发修改和中途异常均拒绝或回滚。审计中没有令牌和授权码明文。
- 复核结果记录复核者和时间，复核后修改自动重新进入队列。JSON 导出与备份恢复保留修改和复核记录。

### 已人工走查

- 桌面和手机视口检查设置页的令牌看图开关、授权码签发/撤销、账单详情的前后值与恢复按钮、复核状态和 MCP 审计列表。
- 使用合成截图故意录错金额、日期、分类，通过 MCP 复核提示词完成预览、修改、查日志和恢复。

### 没有条件验证

- 未使用真实个人账单、真实 Claude 账号或真实 Codex 账号。实际 AI 服务商接收图片的网络链路和隐私提示需要用户在隔离目录自行验证。
- 未连接用户专用 QQ 生产机器人，仍需用户用自己的凭据完成绑定。
